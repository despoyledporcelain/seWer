# seWer

a dark, minimal music player for windows — with soundcloud parsing.

![electron](https://img.shields.io/badge/electron-latest-1c1c1e?style=flat-square&logo=electron&logoColor=white)
![platform](https://img.shields.io/badge/platform-windows-1c1c1e?style=flat-square)

---

## features

- local library scanning with album art & metadata
- waveform progress bar with seek
- hero transition animations between views
- magnet physics on interactive elements
- crossfade & volume control
- soundcloud parsing *(in progress)*

## stack

electron · react 18 (cdn) · babel standalone · space grotesk · music-metadata

## run

```bash
npm install
npm start
```

```bash
npm run build   # → .exe (NSIS)
```
